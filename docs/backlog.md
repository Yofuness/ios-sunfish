Cause (research/notes/rpmh-quarantine-2026-11-03.md, ~75 %): a false timeout — completion is only seen if a poll catches the TCS busy (IRQ_EN masked), and all 9 timeouts in 898 boots (~1 %, at 41-67 s into boot: cx.lvl x5, ldoa9 x3, ldoa10 x1) ended in the same idle/complete state as a success; one global poison flag then blocks every vote. Note: the userland cx.lvl votes are wland's modem proxy votes (wland.c:413-425, as Linux's PIL), lcx/lmx are adspboot's — long-standing, but against the 'no MX/CX from userland' rule: review later.
